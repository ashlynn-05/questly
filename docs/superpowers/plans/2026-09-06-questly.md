# Questly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full Questly path — mood → constraints → live multiplayer room → shared swipe deck → unanimous match → editable multi-stop plan → simulated booking — on the existing Next.js + Convex scaffold.

**Architecture:** Convex owns all state and all realtime. Every client subscribes to one query, `rooms.get`, and the multiplayer layer *is* that subscription — no sockets, no polling. Scoring and itinerary maths are pure TypeScript modules with no Convex imports, so they are tested directly. Latency (Places calls, OpenAI calls) is confined to actions that run behind explicit loading states, never inside the swipe.

**Tech Stack:** Next.js 16 (App Router) · React 19 · Tailwind v4 · Convex 1.45 · Better Auth via `@convex-dev/better-auth` · Google Places API (New) · OpenAI (`text-embedding-3-small`, `gpt-4o-mini`) · vitest + convex-test + @edge-runtime/vm

**Spec:** `docs/superpowers/specs/2026-09-06-questly-design.md`

## Global Constraints

- **Deck size is 9 cards.** Fixed, everywhere.
- **Match rule:** unanimous right-swipe among the members present at the moment the last yes lands. Deck exhaustion declares the top-scored card. It can never deadlock.
- **Editing paths do not overlap:** `plans.replaceStop` is permitted only in a room with exactly one member. Rooms with 2+ members edit only through `proposals`.
- **Majority** means a strict majority of current room members: `Math.floor(n / 2) + 1`. The proposer's yes is recorded automatically. One open proposal per stop.
- **Guests have no account.** A guest is a `members` row with no `userId`, identified by an unguessable `sessionKey` capability token.
- **Identity is always derived server-side.** Use `requireUserId(ctx)` / `safeUserId(ctx)` from `convex/lib/access.ts`, which read `ctx.auth.getUserIdentity()`. **NEVER accept a `userId` or `memberId` as an authorization argument.**
  - Those helpers return `identity.subject`. With exactly one issuer (Better Auth's `convex()` plugin) `subject` *is* the Better Auth user id, which is what `rooms.hostUserId` and `profiles.userId` store and what `t.withIdentity({ subject })` drives in tests. Do not "fix" this to `tokenIdentifier` — it would break the join to the user record and every test.
  - `sessionKey` is the one exception to the no-identifier-argument rule. It is a *capability*, not an identity claim: holding it authorizes acting as one member in one room, and nothing else.
- **ALWAYS include argument validators** on every Convex function, internal ones included.
- **`ctx.vectorSearch` is actions-only.** Never call it from a query or mutation.
- Register private functions with `internalQuery` / `internalMutation` / `internalAction`. A mutation only an action calls is internal, not public.
- **Convex function files export only Convex functions.** Shared helpers live under `convex/lib/`. `convex/schema.ts` is not a function file and may export validators.
- **Money is integer cents.** Never floats. Field names end `Cents`.
- **WCAG 2.2 AA is a product requirement.** Swiping is never the only path — the deck needs equal-weight buttons and a keyboard route. Match, presence and proposal outcomes are live regions. Interactive targets are at least 44px.
- **Design tokens only.** Use the roles in `src/app/globals.css` (`--ground`, `--accent`, `--action`, `--on-action`, …) through the Tailwind aliases (`bg-ground`, `text-accent`, `text-dim`, `border-hairline`, …). Never a raw hex, never a raw palette variable (`--q-*`) in a component. **Orange is a field colour and never carries text**, in either mode.
- **Nothing may imply real partnerships or real bookings.** Demonstration content is labelled as such.

```typescript
/**
 * Ranking maths. Deliberately free of Convex imports so it can be unit-tested
 * directly and reasoned about on its own.
 */

export type Mood = "grass" | "meet" | "treat" | "new";

/** Mood drives the Places query. It is a filter, not a theme. */
export const MOOD_TYPES: Record<Mood, string[]> = {
  grass: ["park", "hiking_area", "beach", "garden"],
  meet: ["bar", "night_club", "community_center", "cafe"],
  treat: ["restaurant", "spa", "movie_theater", "bakery"],
  new: ["art_gallery", "museum", "tourist_attraction", "bowling_alley"],
};

/** Types that are genuinely free to enter, for a $0 budget. */
export const FREE_TYPES = ["park", "hiking_area", "beach", "garden", "tourist_attraction"];

const PRICE_BANDS: Record<string, number> = {
  PRICE_LEVEL_FREE: 0,
  PRICE_LEVEL_INEXPENSIVE: 1500,
  PRICE_LEVEL_MODERATE: 3500,
  PRICE_LEVEL_EXPENSIVE: 7000,
  PRICE_LEVEL_VERY_EXPENSIVE: 12000,
};

/**
 * Places gives a band, never a real price. Partner venues carry a real price
 * and skip this entirely.
 */
export function priceLevelToCents(level: string | null | undefined): number {
  if (level && level in PRICE_BANDS) return PRICE_BANDS[level];
  return PRICE_BANDS.PRICE_LEVEL_MODERATE;
}

/** Haversine, in kilometres. */
export function distanceKm(aLat: number, aLng: number, bLat: number, bLng: number): number {
  const R = 6371;
  const toRad = (d: number) => (d * Math.PI) / 180;
  const dLat = toRad(bLat - aLat);
  const dLng = toRad(bLng - aLng);
  const h =
    Math.sin(dLat / 2) ** 2 +
    Math.cos(toRad(aLat)) * Math.cos(toRad(bLat)) * Math.sin(dLng / 2) ** 2;
  return 2 * R * Math.asin(Math.min(1, Math.sqrt(h)));
}

export type ScoreInput = {
  priceCents: number;
  budgetPerHeadCents: number;
  distanceKm: number;
  radiusKm: number;
  discountPct: number;
  /** 0 = not a partner. Higher tiers rank higher. This is the revenue lever. */
  partnerTier: number;
  moodMatch: boolean;
  /** Cosine similarity against the room's blended taste vector, -1..1. */
  tasteSimilarity: number;
};

const W = {
  partnerBoost: 1.4,
  discountFit: 0.8,
  distanceDecay: 1.0,
  budgetFit: 1.6,
  moodFit: 1.2,
  tasteSimilarity: 1.1,
};

export function scoreQuest(input: ScoreInput): {
  score: number;
  breakdown: Record<string, number>;
} {
  // Budget. Under budget is good; over budget is punished hard enough that a
  // cheap mediocre option always beats an unaffordable great one.
  let budgetFit: number;
  if (input.budgetPerHeadCents === 0) {
    budgetFit = input.priceCents === 0 ? 1 : -2;
  } else if (input.priceCents <= input.budgetPerHeadCents) {
    budgetFit = 1 - (input.priceCents / input.budgetPerHeadCents) * 0.35;
  } else {
    const overBy = (input.priceCents - input.budgetPerHeadCents) / input.budgetPerHeadCents;
    budgetFit = -Math.min(2, overBy * 2);
  }

  const distanceDecay = Math.max(0, 1 - input.distanceKm / Math.max(input.radiusKm, 0.1));
  const discountFit = Math.min(1, input.discountPct / 40);
  const partnerBoost = Math.min(1, input.partnerTier / 3);
  const moodFit = input.moodMatch ? 1 : 0;
  const tasteSimilarity = Math.max(-1, Math.min(1, input.tasteSimilarity));

  const breakdown = {
    partnerBoost: partnerBoost * W.partnerBoost,
    discountFit: discountFit * W.discountFit,
    distanceDecay: distanceDecay * W.distanceDecay,
    budgetFit: budgetFit * W.budgetFit,
    moodFit: moodFit * W.moodFit,
    tasteSimilarity: tasteSimilarity * W.tasteSimilarity,
  };

  return { score: Object.values(breakdown).reduce((a, b) => a + b, 0), breakdown };
}

/** Cosine similarity. Returns 0 when either vector is absent or degenerate. */
export function cosine(a: number[] | undefined, b: number[] | undefined): number {
  if (!a?.length || !b?.length || a.length !== b.length) return 0;
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    na += a[i] * a[i];
    nb += b[i] * b[i];
  }
  if (na === 0 || nb === 0) return 0;
  return dot / (Math.sqrt(na) * Math.sqrt(nb));
}
```

```typescript
/**
 * Itinerary recomputation. Every stop swap has to move the times after it and
 * re-total the cost, or the plan quietly lies to the group.
 */

export type Slot = "meet" | "main" | "after";

export type Stop = {
  id: string;
  slot: Slot;
  placeId?: string;
  name: string;
  startAt: number;
  durationMin: number;
  costPerHeadCents: number;
  note: string;
  source: "llm" | "places" | "manual" | "partner";
  locked: boolean;
};

/** Minutes allowed between stops. Generous on purpose -- nobody is sprinting. */
export const TRAVEL_BUFFER_MIN = 15;

/** Rewrites every startAt from the first stop forward. Pure. */
export function recomputeItinerary(stops: Stop[], startAt: number): Stop[] {
  let cursor = startAt;
  return stops.map((stop, i) => {
    const at = i === 0 ? startAt : cursor;
    cursor = at + (stop.durationMin + TRAVEL_BUFFER_MIN) * 60_000;
    return { ...stop, startAt: at };
  });
}

export function totalPerHeadCents(stops: Stop[]): number {
  return stops.reduce((sum, s) => sum + s.costPerHeadCents, 0);
}

export function isOverBudget(stops: Stop[], budgetPerHeadCents: number): boolean {
  return totalPerHeadCents(stops) > budgetPerHeadCents;
}
```

```typescript
import type { Id, Doc } from "../_generated/dataModel";
import type { QueryCtx, MutationCtx, ActionCtx } from "../_generated/server";

type Ctx = QueryCtx | MutationCtx;
type AnyCtx = Ctx | ActionCtx;

/**
 * Identity is always derived here, never passed in as an argument.
 *
 * `subject` is the Better Auth user id (the convex() plugin puts it there), so
 * it is what rooms.hostUserId and profiles.userId store, and what
 * t.withIdentity({ subject }) drives in tests. There is exactly one issuer, so
 * subject is unambiguous -- do not swap this for tokenIdentifier.
 */
export async function safeUserId(ctx: AnyCtx): Promise<string | null> {
  const identity = await ctx.auth.getUserIdentity();
  return identity?.subject ?? null;
}

export async function requireUserId(ctx: AnyCtx): Promise<string> {
  const userId = await safeUserId(ctx);
  if (!userId) throw new Error("You need to be signed in to do that.");
  return userId;
}

/**
 * Guests have no account, so they cannot be identified by auth. A sessionKey is
 * a capability: holding it authorises acting as that one member in that one
 * room, and nothing else. It is never an identity claim, and no function may
 * accept a memberId or userId for authorisation in its place.
 */
export async function findMember(
  ctx: Ctx,
  roomId: Id<"rooms">,
  sessionKey: string,
): Promise<Doc<"members"> | null> {
  return await ctx.db
    .query("members")
    .withIndex("by_room_session", (q) => q.eq("roomId", roomId).eq("sessionKey", sessionKey))
    .unique();
}

export async function requireMember(
  ctx: Ctx,
  roomId: Id<"rooms">,
  sessionKey: string,
): Promise<Doc<"members">> {
  const member = await findMember(ctx, roomId, sessionKey);
  if (!member) throw new Error("You are not a member of this room.");
  return member;
}

export async function findRoomByCode(ctx: Ctx, code: string): Promise<Doc<"rooms"> | null> {
  return await ctx.db
    .query("rooms")
    .withIndex("by_code", (q) => q.eq("code", code))
    .unique();
}

export async function roomByCode(ctx: Ctx, code: string): Promise<Doc<"rooms">> {
  const room = await findRoomByCode(ctx, code);
  if (!room) throw new Error(`No room with code ${code}.`);
  return room;
}

export async function memberCount(ctx: Ctx, roomId: Id<"rooms">): Promise<number> {
  const members = await ctx.db
    .query("members")
    .withIndex("by_room", (q) => q.eq("roomId", roomId))
    .collect();
  return members.length;
}

/** Strict majority of the current roster. */
export function needed(members: number): number {
  return Math.floor(members / 2) + 1;
}

const ALPHABET = "abcdefghijkmnopqrstuvwxyz23456789"; // no l/1, no o/0

export function newSessionKey(): string {
  const bytes = crypto.getRandomValues(new Uint8Array(24));
  return Array.from(bytes, (b) => ALPHABET[b % ALPHABET.length]).join("");
}

/** Four digits: short enough to read aloud across a table. */
export function newRoomCode(): string {
  const bytes = crypto.getRandomValues(new Uint8Array(4));
  return Array.from(bytes, (b) => String(b % 10)).join("");
}
```

```typescript
import { v } from "convex/values";
import { mutation, query } from "./_generated/server";
import { moodValidator } from "./schema";
import {
  findMember, findRoomByCode, needed, newRoomCode, newSessionKey, requireUserId, roomByCode, safeUserId,
} from "./lib/access";

export const create = mutation({
  args: {
    mood: moodValidator,
    headcount: v.number(),
    budgetPerHeadCents: v.number(),
    whenAt: v.number(),
    centreLat: v.number(),
    centreLng: v.number(),
    radiusKm: v.number(),
    visibility: v.union(v.literal("private"), v.literal("open")),
    hostName: v.string(),
  },
  handler: async (ctx, args) => {
    const userId = await requireUserId(ctx);
    const { hostName, ...room } = args;

    // Four digits collide eventually; retry rather than hand out a dead code.
    let code = newRoomCode();
    for (let i = 0; i < 10; i++) {
      if (!(await findRoomByCode(ctx, code))) break;
      code = newRoomCode();
    }

    const roomId = await ctx.db.insert("rooms", {
      ...room,
      hostUserId: userId,
      status: "lobby",
      code,
    });

    const sessionKey = newSessionKey();
    await ctx.db.insert("members", {
      roomId,
      name: hostName.trim() || "Host",
      userId,
      isHost: true,
      sessionKey,
      joinedAt: Date.now(),
    });

    return { code, sessionKey };
  },
});

export const join = mutation({
  args: { code: v.string(), name: v.string() },
  handler: async (ctx, { code, name }) => {
    const room = await roomByCode(ctx, code);
    if (room.status === "booked") throw new Error("This room has already been booked.");

    const trimmed = name.trim();
    if (!trimmed) throw new Error("A first name is required.");

    // Signed-in users get their id attached; guests do not need one.
    const userId = await safeUserId(ctx);

    const sessionKey = newSessionKey();
    await ctx.db.insert("members", {
      roomId: room._id,
      name: trimmed,
      userId: userId ?? undefined,
      isHost: false,
      sessionKey,
      joinedAt: Date.now(),
    });

    return { code, sessionKey };
  },
});

/**
 * The single subscription the product runs on. Everything reactive -- roster,
 * deck, swipe progress, match, plan, proposals, booking -- arrives here, so a
 * client needs no polling and no socket code of its own.
 *
 * Returns null rather than throwing on an unknown room or a stale session key:
 * a thrown query error would take down the React tree, and the honest response
 * to "I do not know you here" is to send them to /join.
 */
export const get = query({
  args: { code: v.string(), sessionKey: v.string() },
  handler: async (ctx, { code, sessionKey }) => {
    const room = await findRoomByCode(ctx, code);
    if (!room) return null;

    const you = await findMember(ctx, room._id, sessionKey);
    if (!you) return null;

    const members = await ctx.db
      .query("members")
      .withIndex("by_room", (q) => q.eq("roomId", room._id))
      .collect();

    const quests = await ctx.db
      .query("quests")
      .withIndex("by_room_rank", (q) => q.eq("roomId", room._id))
      .order("asc")
      .collect();

    const swipes = await ctx.db
      .query("swipes")
      .withIndex("by_room_member", (q) => q.eq("roomId", room._id))
      .collect();

    const plan = await ctx.db
      .query("plans")
      .withIndex("by_room", (q) => q.eq("roomId", room._id))
      .unique();

    const booking = await ctx.db
      .query("bookings")
      .withIndex("by_room", (q) => q.eq("roomId", room._id))
      .unique();

    const openProposals = await ctx.db
      .query("proposals")
      .withIndex("by_room_status", (q) => q.eq("roomId", room._id).eq("status", "open"))
      .collect();

    const proposals = await Promise.all(
      openProposals.map(async (p) => {
        const votes = await ctx.db
          .query("proposalVotes")
          .withIndex("by_proposal", (q) => q.eq("proposalId", p._id))
          .collect();
        return {
          _id: p._id,
          stopId: p.stopId,
          replacement: p.replacement,
          reason: p.reason,
          proposedByName: members.find((m) => m._id === p.proposedBy)?.name ?? "Someone",
          yes: votes.filter((vote) => vote.vote === "yes").length,
          needed: needed(members.length),
          youVoted: votes.some((vote) => vote.memberId === you._id),
        };
      }),
    );

    const yourSwipes = swipes.filter((s) => s.memberId === you._id);

    // sessionKey is deliberately absent from every member projected here: it is
    // a capability, and one member must never be able to act as another.
    return {
      room: {
        _id: room._id,
        code: room.code,
        mood: room.mood,
        headcount: room.headcount,
        budgetPerHeadCents: room.budgetPerHeadCents,
        whenAt: room.whenAt,
        // Needed by plans.searchStop to bias the search. Not secret.
        centreLat: room.centreLat,
        centreLng: room.centreLng,

 * Someone bails. Their swipes go with them, because unanimity is judged against
 * the current roster -- a departed member's "no" must not hold the room hostage.
 * The host cannot leave: the room is theirs, and an orphaned room has nobody to
 * start the deck.
 */
export const leave = mutation({
  args: { code: v.string(), sessionKey: v.string() },
  handler: async (ctx, { code, sessionKey }): Promise<null> => {
    const room = await roomByCode(ctx, code);
    const member = await findMember(ctx, room._id, sessionKey);
    if (!member) return null; // already gone; leaving twice is not an error
    if (member.isHost) throw new Error("The host cannot leave their own room.");

    const swipes = await ctx.db
      .query("swipes")
      .withIndex("by_room_member", (q) => q.eq("roomId", room._id))
      .collect();
    for (const swipe of swipes) {
      if (swipe.memberId === member._id) await ctx.db.delete(swipe._id);
    }

    const votes = await ctx.db.query("proposalVotes").collect();
    for (const vote of votes) {
      if (vote.memberId === member._id) await ctx.db.delete(vote._id);
    }

    await ctx.db.delete(member._id);
    return null;
  },
});
```

```typescript
import { v } from "convex/values";
import { action, internalMutation, internalQuery } from "./_generated/server";
import { api, internal } from "./_generated/api";
import type { Id } from "./_generated/dataModel";
import {
  MOOD_TYPES, FREE_TYPES, cosine, distanceKm, priceLevelToCents, scoreQuest, type Mood,
} from "./lib/scoring";

/** Long enough that a unanimous match feels earned, short enough to exhaust. */
export const DECK_SIZE = 9;

const questFields = v.object({
  rank: v.number(),
  source: v.union(v.literal("partner"), v.literal("places")),
  placeId: v.string(),
  title: v.string(),
  blurb: v.string(),
  priceLabel: v.string(),
  priceCents: v.number(),
  distanceKm: v.number(),
  discountPct: v.number(),
  photoUrl: v.optional(v.string()),
  mapsUri: v.optional(v.string()),
  websiteUri: v.optional(v.string()),
  score: v.number(),
  scoreBreakdown: v.record(v.string(), v.number()),
});

export const context = internalQuery({
  args: { roomId: v.id("rooms") },
  handler: async (ctx, { roomId }) => {
    const room = await ctx.db.get(roomId);
    if (!room) throw new Error("Room is gone.");

    const partners = (
      await ctx.db.query("venues").withIndex("by_active", (q) => q.eq("active", true)).collect()
    ).filter((venue) => venue.moods.includes(room.mood));

    const members = await ctx.db
      .query("members")
      .withIndex("by_room", (q) => q.eq("roomId", roomId))
      .collect();

    // Guests have no profile, so the signed-in members' taste carries the room.
    const vectors: number[][] = [];
    for (const member of members) {
      if (!member.userId) continue;
      const userId = member.userId;
      const profile = await ctx.db
        .query("profiles")
        .withIndex("by_user", (q) => q.eq("userId", userId))
        .unique();
      if (profile?.tasteVector.length) vectors.push(profile.tasteVector);
    }

    return { room, partners, vectors };
  },
});

export const markBuilding = internalMutation({
  args: { roomId: v.id("rooms") },
  handler: async (ctx, { roomId }) => {
    await ctx.db.patch(roomId, { status: "building" });
    return null;
  },
});

export const insert = internalMutation({
  args: { roomId: v.id("rooms"), quests: v.array(questFields) },
  handler: async (ctx, { roomId, quests }) => {
    const existing = await ctx.db
      .query("quests")
      .withIndex("by_room_rank", (q) => q.eq("roomId", roomId))
      .collect();
    for (const stale of existing) await ctx.db.delete(stale._id);

    for (const q of quests) await ctx.db.insert("quests", { ...q, roomId });
    await ctx.db.patch(roomId, { status: "swiping", deckBuiltAt: Date.now() });
    return quests.length;
  },
});

type Candidate = {
  source: "partner" | "places";
  placeId: string;
  title: string;
  blurb: string;
  priceCents: number;
  distanceKm: number;
  discountPct: number;
  partnerTier: number;
  photoUrl?: string;
  mapsUri?: string;
  websiteUri?: string;
};

/** How many candidates survive to the embedding pass. */
const SHORTLIST_SIZE = 15;

/** Mean of the member taste vectors. Guests contribute nothing. */
function blend(vectors: number[][]): number[] | undefined {
  if (!vectors.length) return undefined;
  const width = vectors[0].length;
  const out = new Array<number>(width).fill(0);
  for (const vec of vectors) {
    if (vec.length !== width) continue;
    for (let i = 0; i < width; i++) out[i] += vec[i] / vectors.length;
  }
  return out;
}

/**
 * One call, all nine blurbs. Returns an array aligned to `titles`, with an
 * empty string wherever the model gave nothing -- the caller falls back to the
 * Places summary, so a missing blurb is a plainer card, never a broken one.
 */
async function writeBlurbs(titles: string[], mood: string): Promise<string[]> {
  const empty = titles.map(() => "");
  const apiKey = process.env.OPENAI_API_KEY;
  if (!apiKey || titles.length === 0) return empty;

  try {
    const response = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${apiKey}` },
      body: JSON.stringify({
        model: "gpt-4o-mini",
        messages: [
          {
            role: "user",
            content: [
              `These Melbourne places are options for a "${mood}" night out:`,
              titles.map((t, i) => `${i}. ${t}`).join("\n"),
              "Write one short line for each -- what it is actually like, the way a",
              "friend would say it. No adjectives stacked up, no marketing.",
              'Return JSON only: {"blurbs":[{"i":number,"text":string}]}',
            ].join("\n"),
          },
        ],
        response_format: { type: "json_object" },
      }),
    });
    if (!response.ok) return empty;

    const data = (await response.json()) as {
      choices?: Array<{ message?: { content?: string } }>;
    };
    const raw = JSON.parse(data.choices?.[0]?.message?.content ?? "{}") as {
      blurbs?: Array<{ i?: unknown; text?: unknown }>;
    };

    const out = [...empty];
    for (const entry of raw.blurbs ?? []) {
      if (typeof entry.i === "number" && typeof entry.text === "string" && out[entry.i] !== undefined) {
        out[entry.i] = entry.text.trim();
      }
    }
    return out;
  } catch {
    return empty;
  }
}

export const build = action({
  args: { code: v.string(), sessionKey: v.string() },
  handler: async (ctx, args): Promise<{ deckSize: number }> => {
    const view = await ctx.runQuery(api.rooms.get, {
      code: args.code,
      sessionKey: args.sessionKey,
    });
    if (!view) throw new Error("You are not a member of this room.");
    const roomId: Id<"rooms"> = view.room._id;

    await ctx.runMutation(internal.deck.markBuilding, { roomId });

    const { room, partners, vectors } = await ctx.runQuery(internal.deck.context, { roomId });
    const free = room.budgetPerHeadCents === 0;
    const includedTypes = free ? FREE_TYPES : MOOD_TYPES[room.mood as Mood];

    const places = await ctx.runAction(api.places.searchNearby, {
      lat: room.centreLat,
      lng: room.centreLng,
      radiusKm: room.radiusKm,
      includedTypes,
      maxResults: 20,
    });

    // Partners first, and injected whether or not Places returned them -- that
    // injection is the inventory the business model is built on.
    const candidates: Candidate[] = partners.map((p) => ({
      source: "partner" as const,
      placeId: p.placeId,
      title: p.name,
      blurb: p.offerText,
      priceCents: p.priceFromCents,
      distanceKm: distanceKm(room.centreLat, room.centreLng, p.lat, p.lng),
      discountPct: p.discountPct,
      partnerTier: p.partnerTier,
      photoUrl: p.photoUrl,
    }));

    const partnerIds = new Set(partners.map((p) => p.placeId));
    for (const place of places.results) {
      if (partnerIds.has(place.id)) continue; // never show a partner twice
      if (place.lat === null || place.lng === null) continue;
      candidates.push({
        source: "places",
        placeId: place.id,
        title: place.name,
        blurb: place.summary ?? place.type ?? "",
        priceCents: free ? 0 : priceLevelToCents(place.priceLevel),
        distanceKm: distanceKm(room.centreLat, room.centreLng, place.lat, place.lng),
        discountPct: 0,
        partnerTier: 0,
        photoUrl: place.photoUrl ?? undefined,
        mapsUri: place.mapsUri ?? undefined,
        websiteUri: place.websiteUri ?? undefined,
      });
    }

    // Two passes. The first ranks on the cheap signals and cuts to a shortlist,
    // so the embedding call costs 15 vectors rather than every Places result.
    const rank = (c: Candidate, tasteSimilarity: number) =>
      scoreQuest({
        priceCents: c.priceCents,
        budgetPerHeadCents: room.budgetPerHeadCents,
        distanceKm: c.distanceKm,
        radiusKm: room.radiusKm,
        discountPct: c.discountPct,
        partnerTier: c.partnerTier,
        // Every candidate came from a mood-filtered query, so this holds.
        moodMatch: true,
        tasteSimilarity,
      });

    const shortlist = candidates
      .map((c) => ({ ...c, ...rank(c, 0) }))
      .sort((a, b) => b.score - a.score)
      .slice(0, SHORTLIST_SIZE);

    // Taste. The room's vector is the mean of its signed-in members' vectors;
    // guests contribute nothing, so the host's carries. With no vectors at all
    // the term is 0 and the ranking falls back to budget, distance and partner.
    const roomTaste = blend(vectors);
    let scored = shortlist;

    if (roomTaste) {
      try {
        const questVectors: number[][] = await ctx.runAction(
          internal.ai.embeddings.embedMany,
          { texts: shortlist.map((c) => `${c.title}. ${c.blurb}`) },
        );
        scored = shortlist
          .map((c, i) => ({ ...c, ...rank(c, cosine(roomTaste, questVectors[i])) }))
          .sort((a, b) => b.score - a.score);
      } catch {
        // Ranking without taste is worse, not broken. Keep the shortlist order.
      }
    }

    scored = scored.slice(0, DECK_SIZE);

    // One batched call writes all nine blurbs. Batched because nine sequential
    // calls is the difference between a loading state and an abandoned room --
    // and because this is the last latency before the swipe, where none is
    // allowed at all.
    const blurbs = await writeBlurbs(scored.map((c) => c.title), room.mood);

    const deckSize: number = await ctx.runMutation(internal.deck.insert, {
      roomId,
      quests: scored.map((c, i) => ({
        rank: i,
        source: c.source,
        placeId: c.placeId,
        title: c.title,
```

```typescript
import type { Mood } from "./scoring";

/**
 * Seven more-likely / less-likely cards. Kept short on purpose: this sits
 * between a new user and their first room, so it is the one screen where every
 * extra card costs a signup.
 */
export const QUIZ_CARDS: Array<{ id: string; text: string; mood: Mood }> = [
  { id: "walk", text: "walking somewhere green instead of sitting down", mood: "grass" },
  { id: "swim", text: "cold water and a towel in a bag", mood: "grass" },
  { id: "strangers", text: "a room where you know one person out of ten", mood: "meet" },
  { id: "loud", text: "somewhere loud enough that you have to lean in", mood: "meet" },
  { id: "long-lunch", text: "one long meal instead of three quick stops", mood: "treat" },
  { id: "spend", text: "spending the whole budget in one good place", mood: "treat" },
  { id: "never-done", text: "something you have genuinely never done", mood: "new" },
];

export type QuizAnswers = Record<string, "more" | "less">;

/**
 * The sentence is what gets embedded. Only the yeses go in -- an embedding of
 * "not this" sits near "this" in vector space and would poison the signal.
 */
export function tasteSentence(answers: QuizAnswers): string {
  const liked = QUIZ_CARDS.filter((c) => answers[c.id] === "more").map((c) => c.text);
  if (!liked.length) return "open to anything, no strong preferences yet";
  return `enjoys ${liked.join("; ")}`;
}

export function moodAffinity(answers: QuizAnswers): Record<string, number> {
  const out: Record<string, number> = { grass: 0, meet: 0, treat: 0, new: 0 };
  for (const card of QUIZ_CARDS) {
    if (answers[card.id] === "more") out[card.mood] += 1;
    if (answers[card.id] === "less") out[card.mood] -= 1;
  }
  return out;
}
```

```typescript
import { recomputeItinerary, type Stop, type Slot } from "./stops";

export type PlanInput = {
  venueName: string;
  headcount: number;
  budgetPerHeadCents: number;
  startAt: number;
  mood: "grass" | "meet" | "treat" | "new";
};

const SLOTS: Slot[] = ["meet", "main", "after"];

export function buildPlanPrompt(input: PlanInput): string {
  const budget =
    input.budgetPerHeadCents === 0
      ? "The budget is $0 per head. Every stop must genuinely cost nothing."
      : `The budget is $${Math.round(input.budgetPerHeadCents / 100)} per head across the whole night.`;

  return [
    `Build a night out in Melbourne for ${input.headcount} people, anchored on ${input.venueName}.`,
    budget,
    "Return 2 to 4 stops as JSON and nothing else, shaped:",
    `{"stops":[{"slot":"meet"|"main"|"after","name":string,"durationMin":number,"costPerHeadCents":number,"note":string}],"shareMessage":string}`,
    'Exactly one stop must be "main" and it must be the anchor venue.',
    "note is one short sentence a friend would actually send.",
    "shareMessage is one line ready to paste into a group chat: where, when, what it costs.",
    "Do not invent prices for the anchor venue beyond the stated budget.",
  ].join("\n");
}

let counter = 0;
const nextId = () => `stop_${Date.now().toString(36)}_${(counter++).toString(36)}`;

/**
 * Never throws. A model that returns prose instead of JSON must still degrade
 * into a usable night, because this runs *after* the match -- the room has
 * already committed and there is nowhere to send them back to.
 */
export function parsePlanResponse(
  text: string,
  startAt: number,
): { stops: Stop[]; shareMessage: string } {
  try {
    const start = text.indexOf("{");
    const end = text.lastIndexOf("}");
    if (start === -1 || end === -1) throw new Error("no json");

    const raw = JSON.parse(text.slice(start, end + 1)) as {
      stops?: Array<Record<string, unknown>>;
      shareMessage?: unknown;
    };
    if (!Array.isArray(raw.stops) || raw.stops.length === 0) throw new Error("no stops");

    const stops: Stop[] = raw.stops.slice(0, 4).map((s) => ({
      id: nextId(),
      slot: SLOTS.includes(s.slot as Slot) ? (s.slot as Slot) : "main",
      name: typeof s.name === "string" && s.name.trim() ? s.name.trim() : "A stop",
      startAt,
      durationMin: typeof s.durationMin === "number" && s.durationMin > 0 ? s.durationMin : 45,
      costPerHeadCents:
        typeof s.costPerHeadCents === "number" && s.costPerHeadCents >= 0
          ? Math.round(s.costPerHeadCents)
          : 0,
      note: typeof s.note === "string" ? s.note : "",
      source: "llm",
      locked: false,
    }));

    return {
      stops: recomputeItinerary(stops, startAt),
      shareMessage:
        typeof raw.shareMessage === "string" && raw.shareMessage.trim()
          ? raw.shareMessage.trim()
          : "Plan's set — see you there.",
    };
  } catch {
    return fallbackPlan({
      venueName: "your quest",
      headcount: 2,
      budgetPerHeadCents: 0,
      startAt,
      mood: "grass",
    });
  }
}

/** The canned night. Used when OpenAI is unavailable, so the demo cannot stall. */
export function fallbackPlan(input: PlanInput): { stops: Stop[]; shareMessage: string } {
  const free = input.budgetPerHeadCents === 0;

  const stops: Stop[] = [
    {
      id: nextId(), slot: "meet", name: `Meet outside ${input.venueName}`,
      startAt: input.startAt, durationMin: 15, costPerHeadCents: 0,
      note: "Whoever gets there first grabs a spot.", source: "llm", locked: false,
    },
    {
      id: nextId(), slot: "main", name: input.venueName,
      startAt: input.startAt, durationMin: 75,
      costPerHeadCents: free ? 0 : Math.round(input.budgetPerHeadCents * 0.7),
      note: "The main event.", source: "llm", locked: false,
    },
  ];

  const time = new Date(input.startAt).toLocaleTimeString("en-AU", {
    hour: "numeric", minute: "2-digit", timeZone: "Australia/Melbourne",
  });

  return {
    stops: recomputeItinerary(stops, input.startAt),
    shareMessage: `${input.venueName} at ${time} — ${
      free ? "free" : `about $${Math.round(input.budgetPerHeadCents / 100)} each`
    }. In?`,
  };
}
```

```typescript
import type { Id } from "../_generated/dataModel";
import type { MutationCtx } from "../_generated/server";
import { recomputeItinerary, totalPerHeadCents, type Stop } from "./stops";

/**
 * The one place a stop is replaced. Recomputes the times after it and re-totals
 * the cost, because a swap that leaves stale times is a plan that lies.
 */
export async function applyStopSwap(
  ctx: MutationCtx,
  roomId: Id<"rooms">,
  stopId: string,
  replacement: Stop,
): Promise<void> {
  const plan = await ctx.db
    .query("plans")
    .withIndex("by_room", (q) => q.eq("roomId", roomId))
    .unique();
  if (!plan) throw new Error("There is no plan to edit yet.");

  const room = await ctx.db.get(roomId);
  if (!room) throw new Error("Room is gone.");

  const index = plan.stops.findIndex((s) => s.id === stopId);
  if (index === -1) throw new Error("That stop is not in this plan.");
  if (plan.stops[index].locked) throw new Error("That stop is locked. Unlock it first.");

  const next = [...plan.stops];
  // The stop keeps its id so open proposals and the UI keep pointing at it.
  next[index] = { ...replacement, id: stopId, locked: false };

  const recomputed = recomputeItinerary(next, room.whenAt);
  await ctx.db.patch(plan._id, {
    stops: recomputed,
    totalPerHeadCents: totalPerHeadCents(recomputed),
  });
}
```

```typescript
import { v } from "convex/values";
import { internalAction, internalMutation, internalQuery } from "./_generated/server";
import { internal } from "./_generated/api";
import { stopValidator } from "./schema";
import { totalPerHeadCents } from "./lib/stops";
import { buildPlanPrompt, parsePlanResponse, fallbackPlan } from "./lib/planPrompt";

export const planContext = internalQuery({
  args: { roomId: v.id("rooms"), questId: v.id("quests") },
  handler: async (ctx, { roomId, questId }) => {
    const room = await ctx.db.get(roomId);
    const quest = await ctx.db.get(questId);
    if (!room || !quest) throw new Error("Room or quest is gone.");

    const members = await ctx.db
      .query("members")
      .withIndex("by_room", (q) => q.eq("roomId", roomId))
      .collect();

    return { room, quest, headcount: members.length };
  },
});

export const writePlan = internalMutation({
  args: {
    roomId: v.id("rooms"),
    questId: v.id("quests"),
    stops: v.array(stopValidator),
    shareMessage: v.string(),
  },
  handler: async (ctx, args) => {
    const existing = await ctx.db
      .query("plans")
      .withIndex("by_room", (q) => q.eq("roomId", args.roomId))
      .unique();

    const doc = { ...args, totalPerHeadCents: totalPerHeadCents(args.stops) };
    if (existing) {
      await ctx.db.patch(existing._id, doc);
      return existing._id;
    }
    return await ctx.db.insert("plans", doc);
  },
});

export const generate = internalAction({
  args: { roomId: v.id("rooms"), questId: v.id("quests") },
  handler: async (ctx, args): Promise<null> => {
    const { room, quest, headcount } = await ctx.runQuery(internal.plans.planContext, args);

    const input = {
      venueName: quest.title,
      headcount,
      budgetPerHeadCents: room.budgetPerHeadCents,
      startAt: room.whenAt,
      mood: room.mood,
    };

    // Start from the usable night, then improve on it if the model cooperates.
    let result = fallbackPlan(input);
    const apiKey = process.env.OPENAI_API_KEY;

    if (apiKey) {
      try {
        const response = await fetch("https://api.openai.com/v1/chat/completions", {
          method: "POST",
          headers: { "Content-Type": "application/json", Authorization: `Bearer ${apiKey}` },
          body: JSON.stringify({
            model: "gpt-4o-mini",
            messages: [{ role: "user", content: buildPlanPrompt(input) }],
            response_format: { type: "json_object" },
          }),
        });
        if (response.ok) {
          const data = (await response.json()) as {
            choices?: Array<{ message?: { content?: string } }>;
          };
          const text = data.choices?.[0]?.message?.content;
          if (text) result = parsePlanResponse(text, room.whenAt);
        }
      } catch {
        // The fallback already holds a usable night. Never leave a matched room
        // without a plan just because a third party was slow.
      }
    }

    await ctx.runMutation(internal.plans.writePlan, {
      roomId: args.roomId,
      questId: args.questId,
      stops: result.stops,
      shareMessage: result.shareMessage,
    });
    return null;
  },
});
```

```typescript
import { v } from "convex/values";
import { mutation } from "./_generated/server";
import { internal } from "./_generated/api";
import type { Id } from "./_generated/dataModel";
import { requireMember, roomByCode } from "./lib/access";

export const cast = mutation({
  args: {
    code: v.string(),
    sessionKey: v.string(),
    questId: v.id("quests"),
    dir: v.union(v.literal("yes"), v.literal("no")),
  },
  handler: async (ctx, args): Promise<{ matched: boolean; questId: Id<"quests"> | null }> => {
    const room = await roomByCode(ctx, args.code);
    const member = await requireMember(ctx, room._id, args.sessionKey);

    // A late swipe from a slow phone must not reopen a decided room.
    if (room.status === "matched" || room.status === "booked") {
      return { matched: true, questId: room.matchedQuestId ?? null };
    }

    // Idempotent: re-swiping the same card overwrites rather than duplicates.
    const onThisQuest = await ctx.db
      .query("swipes")
      .withIndex("by_room_quest", (q) => q.eq("roomId", room._id).eq("questId", args.questId))
      .collect();
    const mine = onThisQuest.find((s) => s.memberId === member._id);
    if (mine) {
      await ctx.db.patch(mine._id, { dir: args.dir });
    } else {
      await ctx.db.insert("swipes", {
        roomId: room._id, questId: args.questId, memberId: member._id, dir: args.dir,
      });
    }

    const members = await ctx.db
      .query("members")
      .withIndex("by_room", (q) => q.eq("roomId", room._id))
      .collect();

    const swipes = await ctx.db
      .query("swipes")
      .withIndex("by_room_member", (q) => q.eq("roomId", room._id))
      .collect();

    const quests = await ctx.db
      .query("quests")
      .withIndex("by_room_rank", (q) => q.eq("roomId", room._id))
      .order("asc")
      .collect();

    // Unanimity is judged against the CURRENT roster: someone who left stops
    // being required, and someone who joins must still clear the passed cards.
    const yesesFor = (questId: Id<"quests">) =>
      swipes.filter((s) => s.questId === questId && s.dir === "yes").map((s) => s.memberId);

    const unanimous = quests.find(
      (q) => members.length > 0 && members.every((m) => yesesFor(q._id).includes(m._id)),
    );

    let winner: Id<"quests"> | null = unanimous?._id ?? null;

    if (!winner && quests.length > 0) {
      // Deck exhausted with no agreement -- declare the top-scored card rather
      // than deadlock. This is the safety net that makes a live demo safe.
      const everyoneDone = members.every(
        (m) => swipes.filter((s) => s.memberId === m._id).length >= quests.length,
      );
      if (everyoneDone) winner = quests[0]._id;
    }

    if (!winner) return { matched: false, questId: null };

    await ctx.db.patch(room._id, { status: "matched", matchedQuestId: winner });
    // The plan is built out of band: the match must land on every phone now,
    // not after an LLM round trip.
    await ctx.scheduler.runAfter(0, internal.plans.generate, {
      roomId: room._id,
      questId: winner,
    });
    return { matched: true, questId: winner };
  },
});
```

```typescript
import { v } from "convex/values";
import { mutation } from "./_generated/server";
import { stopValidator } from "./schema";
import { memberCount, needed, requireMember, roomByCode } from "./lib/access";
import { applyStopSwap } from "./lib/swap";

export const open = mutation({
  args: {
    code: v.string(),
    sessionKey: v.string(),
    stopId: v.string(),
    replacement: stopValidator,
    reason: v.string(),
  },
  handler: async (ctx, args) => {
    const room = await roomByCode(ctx, args.code);
    const member = await requireMember(ctx, room._id, args.sessionKey);

    const clash = await ctx.db
      .query("proposals")
      .withIndex("by_room_stop", (q) => q.eq("roomId", room._id).eq("stopId", args.stopId))
      .filter((q) => q.eq(q.field("status"), "open"))
      .first();
    if (clash) throw new Error("Someone has already proposed a change to that stop.");

    const proposalId = await ctx.db.insert("proposals", {
      roomId: room._id,
      stopId: args.stopId,
      proposedBy: member._id,
      replacement: args.replacement,
      reason: args.reason,
      status: "open",
    });

    // Proposing is agreeing. Recorded rather than implied, so the count is real.
    await ctx.db.insert("proposalVotes", { proposalId, memberId: member._id, vote: "yes" });

    const total = await memberCount(ctx, room._id);
    if (1 >= needed(total)) {
      await applyStopSwap(ctx, room._id, args.stopId, args.replacement);
      await ctx.db.patch(proposalId, { status: "accepted" });
      return { proposalId, accepted: true };
    }
    return { proposalId, accepted: false };
  },
});

export const vote = mutation({
  args: {
    code: v.string(),
    sessionKey: v.string(),
    proposalId: v.id("proposals"),
    vote: v.union(v.literal("yes"), v.literal("no")),
  },
  handler: async (ctx, args) => {
    const room = await roomByCode(ctx, args.code);
    const member = await requireMember(ctx, room._id, args.sessionKey);

    const proposal = await ctx.db.get(args.proposalId);
    // Checking the room too: a proposal id from another room is not a vote here.
    if (!proposal || proposal.roomId !== room._id) throw new Error("No such proposal.");
    if (proposal.status !== "open") return { accepted: proposal.status === "accepted" };

    const existing = await ctx.db
      .query("proposalVotes")
      .withIndex("by_proposal", (q) => q.eq("proposalId", args.proposalId))
      .collect();

    const mine = existing.find((v) => v.memberId === member._id);
    if (mine) {
      await ctx.db.patch(mine._id, { vote: args.vote });
    } else {
      await ctx.db.insert("proposalVotes", {
        proposalId: args.proposalId, memberId: member._id, vote: args.vote,
      });
    }

    const fresh = await ctx.db
      .query("proposalVotes")
      .withIndex("by_proposal", (q) => q.eq("proposalId", args.proposalId))
      .collect();

    const yes = fresh.filter((v) => v.vote === "yes").length;
    const total = await memberCount(ctx, room._id);

    // Resolves the instant the majority lands -- no timer, no dead air.
    if (yes >= needed(total)) {
      await applyStopSwap(ctx, room._id, proposal.stopId, proposal.replacement);
      await ctx.db.patch(args.proposalId, { status: "accepted" });
      return { accepted: true };
    }
    return { accepted: false };
  },
});
```

```typescript
import { v } from "convex/values";
import { mutation } from "./_generated/server";
import { requireMember, roomByCode } from "./lib/access";

function mapsSearchUrl(name: string): string {
  return `https://www.google.com/maps/search/?api=1&query=${encodeURIComponent(`${name} Melbourne`)}`;
}

/**
 * Simulated. No table is held and no venue is contacted -- the UI says so in
 * plain words, and nothing here may imply otherwise.
 */
export const confirm = mutation({
  args: { code: v.string(), sessionKey: v.string() },
  handler: async (ctx, args) => {
    const room = await roomByCode(ctx, args.code);
    // Any member can book. Whoever is holding their phone when the group agrees
    // should not have to hand it to the host.
    await requireMember(ctx, room._id, args.sessionKey);

    const existing = await ctx.db
      .query("bookings")
      .withIndex("by_room", (q) => q.eq("roomId", room._id))
      .unique();
    if (existing) return { ref: existing.ref, deepLink: existing.deepLink };

    if (!room.matchedQuestId) throw new Error("There is nothing to book yet.");
    const quest = await ctx.db.get(room.matchedQuestId);
    if (!quest) throw new Error("There is nothing to book yet.");

    const plan = await ctx.db
      .query("plans")
      .withIndex("by_room", (q) => q.eq("roomId", room._id))
      .unique();

    const members = await ctx.db
      .query("members")
      .withIndex("by_room", (q) => q.eq("roomId", room._id))
      .collect();

    const perHead = plan?.totalPerHeadCents ?? quest.priceCents;
    const deepLink = quest.mapsUri ?? quest.websiteUri ?? mapsSearchUrl(quest.title);

    // The room code doubles as the reference -- one number to read aloud.
    const ref = `QL-${room.code}`;

    await ctx.db.insert("bookings", {
      roomId: room._id,
      questId: quest._id,
      ref,
      headcount: members.length,
      totalCents: perHead * members.length,
      status: "simulated",
      deepLink,
    });

    await ctx.db.patch(room._id, { status: "booked" });
    return { ref, deepLink };
  },
});
```

```typescript
function toOptions(
  results: Array<{
    id: string; name: string; address: string;
    summary: string | null; priceLevel: string | null;
  }>,
  slot: Slot,
  free: boolean,
  prefix: string,
): Stop[] {
  return results.slice(0, 6).map((place, i) => ({
    id: `${prefix}_${i}`,
    slot,
    placeId: place.id,
    name: place.name,
    // startAt is rewritten by applyStopSwap, so a placeholder is correct here.
    startAt: 0,
    durationMin: 60,
    costPerHeadCents: free ? 0 : priceLevelToCents(place.priceLevel),
    note: place.summary ?? place.address,
    source: "manual" as const,
    locked: false,
  }));
}

/**
 * "Ask Claude" -- three alternatives for one stop, with the stops around it as
 * context so the suggestion fits the night rather than replacing it.
 *
 * Falls back to a plain nearby search when the model is unavailable, so the
 * button always does something. An empty sheet reads as a broken feature.
 */
export const suggestStop = action({
  args: { code: v.string(), sessionKey: v.string(), stopId: v.string() },
  handler: async (ctx, args): Promise<{ options: Stop[] }> => {
    const view = await ctx.runQuery(api.rooms.get, {
      code: args.code,
      sessionKey: args.sessionKey,
    });
    if (!view) throw new Error("You are not a member of this room.");
    if (!view.plan) throw new Error("There is no plan to edit yet.");

    const target = view.plan.stops.find((s) => s.id === args.stopId);
    if (!target) throw new Error("That stop is not in this plan.");

    const free = view.room.budgetPerHeadCents === 0;
    const keeping = view.plan.stops
      .filter((s) => s.id !== args.stopId)
      .map((s) => `${s.slot}: ${s.name}${s.locked ? " (locked, do not change)" : ""}`)
      .join("\n");

    const apiKey = process.env.OPENAI_API_KEY;
    if (apiKey) {
      try {
        const prompt = [
          `A group of ${view.members.length} is out in Melbourne. These stops are staying:`,
          keeping || "(none -- this is the only stop)",
          `Replace the "${target.slot}" stop, currently "${target.name}".`,
          free
            ? "The budget is $0 per head, so the replacement must genuinely cost nothing."
            : `The whole night must stay under $${Math.round(view.room.budgetPerHeadCents / 100)} per head.`,
          "Return 3 real Melbourne options as JSON and nothing else, shaped:",
          `{"options":[{"name":string,"durationMin":number,"costPerHeadCents":number,"note":string}]}`,
          "note is one short sentence saying why it fits.",
        ].join("\n");

        const response = await fetch("https://api.openai.com/v1/chat/completions", {
          method: "POST",
          headers: { "Content-Type": "application/json", Authorization: `Bearer ${apiKey}` },
          body: JSON.stringify({
            model: "gpt-4o-mini",
            messages: [{ role: "user", content: prompt }],
            response_format: { type: "json_object" },
          }),
        });

        if (response.ok) {
          const data = (await response.json()) as {
            choices?: Array<{ message?: { content?: string } }>;
          };
          const raw = JSON.parse(data.choices?.[0]?.message?.content ?? "{}") as {
            options?: Array<Record<string, unknown>>;
          };

          const options: Stop[] = (raw.options ?? []).slice(0, 3).map((o, i) => ({
            id: `llm_${i}`,
            slot: target.slot,
            name: typeof o.name === "string" && o.name.trim() ? o.name.trim() : "A stop",
            startAt: 0,
            durationMin: typeof o.durationMin === "number" && o.durationMin > 0 ? o.durationMin : 60,
            costPerHeadCents:
              free || typeof o.costPerHeadCents !== "number" || o.costPerHeadCents < 0
                ? 0
                : Math.round(o.costPerHeadCents),
            note: typeof o.note === "string" ? o.note : "",
            source: "llm" as const,
            locked: false,
          }));

          if (options.length) return { options };
        }
      } catch {
        // Fall through to the search below rather than surfacing an empty sheet.
      }
    }

    const found = await ctx.runAction(api.places.searchText, {
      query: target.name,
      lat: view.room.centreLat,
      lng: view.room.centreLng,
      radiusKm: view.room.radiusKm,
    });
    return {
      options: toOptions(found.results, target.slot, free, "nearby").slice(0, 3),
    };
  },
});
```

```typescript
"use client";

import { useCallback, useEffect, useState } from "react";

/**
 * A guest's proof that they belong to a room. Stored per-room so one device can
 * hold two rooms at once -- which is exactly what happens when the app is
 * demoed on a laptop and a phone side by side.
 */
const keyFor = (code: string) => `questly-session-${code}`;

export function useSessionKey(code: string) {
  const [sessionKey, setSessionKey] = useState<string | null>(null);
  // `ready` separates "no key" from "have not looked yet". Without it the room
  // page redirects to /join on its first render, every time.
  const [ready, setReady] = useState(false);

  useEffect(() => {
    setReady(false);
    try {
      setSessionKey(localStorage.getItem(keyFor(code)));
    } catch {
      setSessionKey(null); // private browsing -- the room asks them to rejoin
    }
    setReady(true);
  }, [code]);

  const store = useCallback(
    (next: string) => {
      try {
        localStorage.setItem(keyFor(code), next);
      } catch {
        // Still works for this page's lifetime; only survival is lost.
      }
      setSessionKey(next);
      setReady(true);
    },
    [code],
  );

  return { sessionKey, ready, store };
}
```

```typescript
"use client";

import type { ReactNode } from "react";
import Link from "next/link";

type Variant = "action" | "quiet" | "raised" | "ghost";

const SURFACE: Record<Variant, string> = {
  // Orange is a FIELD colour. It carries --on-action ink, never its own text.
  action: "bg-action text-on-action",
  quiet: "bg-action-quiet text-on-action",
  raised: "bg-ground-raised text-text",
  ghost: "bg-transparent text-text border border-hairline",
};

type Props = {
  variant?: Variant;
  selected?: boolean;
  label: string;
  sub?: string;
  right?: ReactNode;
  icon?: ReactNode;
  disabled?: boolean;
  href?: string;
  onClick?: () => void;
  className?: string;
};

/**
 * min-h-[44px] is not decoration: WCAG 2.2 AA target size is a product
 * requirement here, and these are the controls a whole group taps at once on
 * phones held one-handed.
 */
export function Plate({
  variant = "raised",
  selected = false,
  label,
  sub,
  right,
  icon,
  disabled = false,
  href,
  onClick,
  className = "",
}: Props) {
  const base = [
    "group flex min-h-[44px] w-full items-center gap-3 rounded-[6px] px-4 py-3",
    "text-left transition-[transform,background-color] duration-150",
    "active:translate-y-[1px] disabled:opacity-50 disabled:pointer-events-none",
    SURFACE[variant],
    selected ? "ring-2 ring-accent ring-offset-2 ring-offset-ground" : "",
    className,
  ].join(" ");

  const inner = (
    <>
      {icon ? <span className="shrink-0">{icon}</span> : null}
      <span className="min-w-0 flex-1">
        <span className="board block text-[11px] opacity-80">{label}</span>
        {sub ? <span className="mt-1 block text-[13px] leading-snug">{sub}</span> : null}
      </span>
      {right ? <span className="num shrink-0 text-[15px]">{right}</span> : null}
    </>
  );

  // A navigation control stays a link, so middle-click and open-in-new-tab work.
  if (href) {
    return (
      <Link href={href} className={base}>
        {inner}
      </Link>
    );
  }

  return (
    <button type="button" onClick={onClick} disabled={disabled} className={base}>
      {inner}
    </button>
  );
}
```

```typescript
import { use, useState } from "react";
import { useRouter } from "next/navigation";
import { useMutation } from "convex/react";
import { api } from "@convex/_generated/api";
import { Plate } from "@/components/questly/Plate";
import { useSessionKey } from "@/lib/session";

  );
```

```typescript
import { use, useEffect } from "react";
import { useRouter } from "next/navigation";
import { useQuery } from "convex/react";
import type { FunctionReturnType } from "convex/server";
import { api } from "@convex/_generated/api";

export default function RoomPage({ params }: { params: Promise<{ code: string }> }) {
  const { code } = use(params);
  const router = useRouter();

  const view = useQuery(api.rooms.get, sessionKey ? { code, sessionKey } : "skip");

  useEffect(() => {

      {view.room.status === "lobby" ? (
        <Lobby view={view} code={code} sessionKey={sessionKey} />
```

```typescript
"use client";

import { useCallback, useEffect, useState } from "react";
import { useMutation } from "convex/react";
import { api } from "@convex/_generated/api";
import { Plate } from "@/components/questly/Plate";
import { MapTile } from "@/components/questly/frame";
import type { RoomView } from "./page";

export function Deck({
  view, code, sessionKey,
}: {
  view: RoomView; code: string; sessionKey: string;
}) {
  const cast = useMutation(api.swipes.cast);
  const [busy, setBusy] = useState(false);

  const index = view.progress.swipedByYou;
  const quest = view.quests[index];

  const swipe = useCallback(
    async (dir: "yes" | "no") => {
      if (!quest || busy) return;
      setBusy(true);
      try {
        await cast({ code, sessionKey, questId: quest._id, dir });
      } finally {
        setBusy(false);
      }
    },
    [quest, busy, cast, code, sessionKey],
  );

  // Swiping is never the only path: the buttons below are the primary control
  // and the arrow keys are the shortcut. A gesture would be a third option.
  useEffect(() => {
    function onKey(e: KeyboardEvent) {
      if (e.key === "ArrowRight") void swipe("yes");
      if (e.key === "ArrowLeft") void swipe("no");
    }
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, [swipe]);

  if (!quest) {
    return (
      <section className="flex min-h-[60vh] flex-col items-center justify-center gap-3 px-5">
        <p className="board text-[11px] text-accent">Your deck is done</p>
        <p aria-live="polite" className="text-center text-[15px] text-dim">
          {view.progress.waitingOn.length > 0
            ? `Waiting on ${view.progress.waitingOn.join(", ")}.`
            : "Working out where you all landed…"}
        </p>
      </section>
    );
  }

  return (
    <section className="flex flex-col gap-5 px-5 py-8">
      <div className="flex items-baseline justify-between gap-3">
        <p className="board text-[11px] text-accent">
          <span className="num">{index + 1}</span> of{" "}
          <span className="num">{view.quests.length}</span>
        </p>
        <p aria-live="polite" className="text-right text-[12px] text-dim">
          {view.progress.waitingOn.length > 0
            ? `Still swiping: ${view.progress.waitingOn.join(", ")}`
            : "Everyone is through"}
        </p>
      </div>

      <article
        role="group"
        aria-label={`Option ${index + 1} of ${view.quests.length}: ${quest.title}`}
        className="overflow-hidden rounded-[10px] bg-ground-raised"
      >
        {quest.photoUrl ? (
          // eslint-disable-next-line @next/next/no-img-element -- Places photo URLs are signed redirects, not a fixed remote pattern
          <img src={quest.photoUrl} alt="" className="h-[200px] w-full object-cover" />
        ) : (
          <MapTile className="h-[200px] w-full" />
        )}

        <div className="flex flex-col gap-3 p-4">
          <h2 className="display text-[28px] text-text">{quest.title}</h2>
          {quest.blurb ? <p className="text-[14px] leading-snug text-dim">{quest.blurb}</p> : null}

          <dl className="m-0 flex gap-6">
            <div>
              <dt className="board text-[10px] text-dim">Cost</dt>
              <dd className="num m-0 text-[18px] text-text">{quest.priceLabel}</dd>
            </div>
            <div>
              <dt className="board text-[10px] text-dim">Away</dt>
              <dd className="num m-0 text-[18px] text-text">{quest.distanceKm} km</dd>
            </div>
            {quest.discountPct > 0 ? (
              <div>
                <dt className="board text-[10px] text-dim">Deal</dt>
                <dd className="num m-0 text-[18px] text-accent">−{quest.discountPct}%</dd>
              </div>
            ) : null}
          </dl>
        </div>
      </article>

      <div className="flex gap-3">
        <Plate variant="raised" label="Nah" disabled={busy} onClick={() => void swipe("no")} />
        <Plate variant="action" label="I'm in" disabled={busy} onClick={() => void swipe("yes")} />
      </div>
      <p className="text-center text-[12px] text-dim">Arrow keys work too.</p>
    </section>
  );
}
```

```typescript
"use client";

import { useState } from "react";
import { useAction, useMutation } from "convex/react";
import { api } from "@convex/_generated/api";
import type { Stop } from "@convex/lib/stops";
import { Plate } from "@/components/questly/Plate";
import { Rail, RailNode } from "@/components/questly/Rail";
import type { RoomView } from "./page";

const time = (at: number) =>
  new Date(at).toLocaleTimeString("en-AU", { hour: "numeric", minute: "2-digit" });

const money = (cents: number) => (cents === 0 ? "Free" : `$${Math.round(cents / 100)}`);

type SheetTab = "ask" | "search";

export function Plan({
  view, code, sessionKey,
}: {
  view: RoomView; code: string; sessionKey: string;
}) {
  const setLocked = useMutation(api.plans.setLocked);
  const replaceStop = useMutation(api.plans.replaceStop);
  const openProposal = useMutation(api.proposals.open);
  const voteOnProposal = useMutation(api.proposals.vote);
  const suggestStop = useAction(api.plans.suggestStop);
  const searchStop = useAction(api.plans.searchStop);
  const confirm = useMutation(api.bookings.confirm);

  const [sheetFor, setSheetFor] = useState<string | null>(null);
  const [tab, setTab] = useState<SheetTab>("ask");
  const [options, setOptions] = useState<Stop[]>([]);
  const [queryText, setQueryText] = useState("");
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const plan = view.plan;
  // The server enforces this split too. The UI must never offer a control the
  // server is going to reject.
  const isGroup = view.members.length > 1;

  if (!plan) {
    return (
      <section className="flex min-h-[60vh] flex-col items-center justify-center gap-3 px-5">
        <p className="board flap text-[11px] text-accent">It&rsquo;s a match</p>
        <p className="text-[15px] text-dim">Writing the plan…</p>
      </section>
    );
  }

  const overBudget = plan.totalPerHeadCents > view.room.budgetPerHeadCents;

  async function loadOptions(stopId: string, which: SheetTab, text = "") {
    setBusy(true);
    setError(null);
    try {
      const stop = plan.stops.find((s) => s.id === stopId)!;
      const result =
        which === "ask"
          ? await suggestStop({ code, sessionKey, stopId })
          : await searchStop({ code, sessionKey, query: text, slot: stop.slot });
      setOptions(result.options);
    } catch (e) {
      setError(e instanceof Error ? e.message : "Could not load options.");
      setOptions([]);
    } finally {
      setBusy(false);
    }
  }

  async function choose(stopId: string, replacement: Stop) {
    setBusy(true);
    setError(null);
    try {
      if (isGroup) {
        await openProposal({ code, sessionKey, stopId, replacement, reason: "" });
      } else {
        await replaceStop({ code, sessionKey, stopId, replacement });
      }
      setSheetFor(null);
      setOptions([]);
    } catch (e) {
      setError(e instanceof Error ? e.message : "Could not change that stop.");
    } finally {
      setBusy(false);
    }
  }

  return (
    <section className="flex flex-col gap-7 px-5 py-8">
      <div>
        <p className="board text-[11px] text-accent">The plan</p>
        <h1 className="display mt-2 text-[34px] text-text">
          {plan.stops.find((s) => s.slot === "main")?.name ?? "Your night"}
        </h1>
      </div>

      <div className="relative pl-14">
        <Rail drawing />
        <ol className="m-0 flex list-none flex-col gap-7 p-0">
          {plan.stops.map((stop) => {
            const proposal = view.proposals.find((p) => p.stopId === stop.id);
            return (
              <li key={stop.id} className="relative">
                <RailNode top={6} state={proposal ? "live" : stop.locked ? "locked" : "open"} />

                <div className="flex items-baseline justify-between gap-3">
                  <div className="min-w-0">
                    <p className="board text-[10px] text-accent">
                      {stop.slot} · <span className="num">{time(stop.startAt)}</span>
                    </p>
                    <p className="mt-1 text-[19px] leading-snug text-text">{stop.name}</p>
                    {stop.note ? <p className="mt-1 text-[13px] text-dim">{stop.note}</p> : null}
                  </div>
                  <p className="num shrink-0 text-[17px] text-text">
                    {money(stop.costPerHeadCents)}
                  </p>
                </div>

                <div className="mt-3 flex gap-2">
                  <Plate
                    variant="ghost"
                    label={stop.locked ? "Locked — unlock" : "Lock this in"}
                    onClick={() =>
                      void setLocked({ code, sessionKey, stopId: stop.id, locked: !stop.locked })
                    }
                  />
                  {!stop.locked ? (
                    <Plate
                      variant="ghost"
                      label={isGroup ? "Propose a change" : "Swap it"}
                      onClick={() => {
                        setSheetFor(stop.id);
                        setTab("ask");
                        setOptions([]);
                        void loadOptions(stop.id, "ask");
                      }}
                    />
                  ) : null}
                </div>

                {proposal ? (
                  <div aria-live="polite" className="mt-3 rounded-[6px] border border-hairline p-3">
                    <p className="board text-[10px] text-accent">
                      {proposal.proposedByName} wants to swap this
                    </p>
                    <p className="mt-1 text-[15px] text-text">{proposal.replacement.name}</p>
                    <p className="num mt-1 text-[13px] text-dim">
                      {proposal.yes} of {proposal.needed} needed
                    </p>
                    {proposal.youVoted ? (
                      <p className="mt-2 text-[12px] text-dim">Your vote is in.</p>
                    ) : (
                      <div className="mt-3 flex gap-2">
                        <Plate
                          variant="action"
                          label="Yes"
                          onClick={() =>
                            void voteOnProposal({
                              code, sessionKey, proposalId: proposal._id, vote: "yes",
                            })
                          }
                        />
                        <Plate
                          variant="ghost"
                          label="No"
                          onClick={() =>
                            void voteOnProposal({
                              code, sessionKey, proposalId: proposal._id, vote: "no",
                            })
                          }
                        />
                      </div>
                    )}
                  </div>
                ) : null}

                {sheetFor === stop.id ? (
                  <div className="mt-3 rounded-[6px] border border-hairline p-3">
                    <div className="flex gap-2">
                      <Plate
                        variant={tab === "ask" ? "action" : "ghost"}
                        label="Ask Claude"
                        onClick={() => { setTab("ask"); void loadOptions(stop.id, "ask"); }}
                      />
                      <Plate
                        variant={tab === "search" ? "action" : "ghost"}
                        label="Pick it yourself"
                        onClick={() => { setTab("search"); setOptions([]); }}
                      />
                    </div>

                    {tab === "search" ? (
                      <form
                        className="mt-3 flex gap-2"
                        onSubmit={(e) => {
                          e.preventDefault();
                          void loadOptions(stop.id, "search", queryText);
                        }}
                      >
                        <label htmlFor={`q-${stop.id}`} className="sr-only">
                          Search for a place

                          value={queryText}

                      {!busy && options.length === 0 ? (
                        <p className="text-[13px] text-dim">
                          {tab === "search"
                            ? "Type what you are after."
                            : "Nothing came back. Try picking it yourself."}
                        </p>
                      ) : null}

                          key={option.id}
                          variant="raised"
                          label={option.name}

                      variant="ghost"
                      label="Close"
                      className="mt-3"
                      onClick={() => setSheetFor(null)}

                  </div>
                ) : null}

            );
          })}
        </ol>
      </div>

      <div className="flex items-baseline justify-between border-t border-hairline pt-4">
        <p className="board text-[11px] text-dim">Per head</p>

        </p>

            await confirm({ code, sessionKey });

            setError(e instanceof Error ? e.message : "Could not book that.");
```

```typescript
"use client";

import { useState } from "react";
import { Plate } from "@/components/questly/Plate";
import type { RoomView } from "./page";

export function Booked({ view }: { view: RoomView }) {
  const [copied, setCopied] = useState(false);
  const booking = view.booking;
  if (!booking) return null;

  const perHead = booking.headcount > 0 ? booking.totalCents / booking.headcount : 0;

  return (
    <section className="flex flex-col gap-8 px-5 py-10">

        <p className="board text-[11px] text-accent">Booked</p>
```

```typescript
const DECK_TTL_MS = 60 * 60 * 1000;

/** Two rooms asking the same question within the hour get the same answer. */
const cacheKey = (r: {
  mood: string;
  radiusKm: number;
  budgetPerHeadCents: number;
  centreLat: number;
  centreLng: number;
}) =>
  [r.mood, r.radiusKm, r.budgetPerHeadCents, r.centreLat.toFixed(2), r.centreLng.toFixed(2)].join("|");

/**
 * A second demo run must be instant and must not depend on the network. Places
 * results for the same area and constraints do not meaningfully change inside
 * an hour, so re-querying spends money to get the same nine cards.
 */
export const recentDeck = internalQuery({
  args: { roomId: v.id("rooms") },
  handler: async (ctx, { roomId }) => {
    const room = await ctx.db.get(roomId);
    if (!room) return null;

    const cutoff = Date.now() - DECK_TTL_MS;
    const rooms = await ctx.db.query("rooms").collect();

    for (const other of rooms) {
      if (other._id === roomId) continue;
      if (!other.deckBuiltAt || other.deckBuiltAt < cutoff) continue;
      if (cacheKey(other) !== cacheKey(room)) continue;

      const quests = await ctx.db
        .query("quests")
        .withIndex("by_room_rank", (q) => q.eq("roomId", other._id))
        .order("asc")
        .collect();
      if (quests.length === 0) continue;

      // Strip the system fields and the other room's id -- insert re-adds them.
      return quests.map(({ _id, _creationTime, roomId: _room, ...rest }) => rest);
    }
    return null;
  },
});
```
